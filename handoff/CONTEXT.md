# CONTEXT —— 术语表

只放词汇，不放实现。（实现细节见 `README.md`，决策见 `adr/`。）

## 交接（succession）

把一个进行中的任务**交给一个新的顶层会话**继续，旧会话停止推进。

不是"接着聊"：继任者是新的执行主体，只有一份便条级的交接文档，其余信息靠自己检索。

## 继任会话（successor session）

承接交接的那个新顶层会话。它是**新的主会话**，拥有完整主会话权限（含两档位切换），不是子代理。

**它的第一职责是读懂并汇报概况，然后问用户"这轮做什么"**；交接文档里的"下一步"只是候选，不是派工单（见 `README.md` §4）。

## 交接文档 / INDEX（handoff note）

交接的唯一必读产物，便条级（六字段、≤70 行 / ≤1.5k tokens）。它描述**目标、已完成、未决、候选下一步、硬约束、验证方式**，以及"去哪找"，而不是承载内容本身。

## 委派（delegation）

主会话不变，把一件独立的事交给**子代理**去做。与交接的区别：委派**增加**一条并行上下文，交接**替换**当前上下文。

## 子代理（subagent）

被委派出去的执行者。默认只执行、不派生新的子代理、不回长文。

## 扇出（fan-out）

一个委派任务在未受约束时自行派生出更多子代理的链式扩张。已被结构性禁止（见 `README.md` §5）。

## 压缩（compaction）

在**同一会话内**把较早的历史重写成摘要。与交接的区别：压缩换历史不换人，且会作废被改写位置之后的前缀缓存。

**压缩不是交接。**

## 冷读（cold re-read）

一次请求里上下文没有被缓存命中、按全价重新计费的那部分。发生在：会话久置后再续、上下文被改写、某个档位在本会话首次出现。

## 档位（gear / reasoning effort）

模型思考量档位。**可用集合是按模型算的，不是全局事实**：适配器白名单是 `off`/`low`/`high`/`max`，
但某档能不能用取决于该模型的 `thinkingLevelMap`（`null` = 不可用）——例：`zai/glm-5.3` 没有 `off`。
查当前默认模型：`node tools/show-effort-levels.mjs --current`。详见 `README.md` §6。

档位是**会话级**属性：一个会话选定后不中途更换；换档等于换一条缓存谱系。

## 检索预算（retrieval budget）

继任者在一个工作轮次内允许花在"自己找信息"上的开销上限，以及固定顺序：本地优先，联网兜底。

## 结论状态（claim status）

交接文档里每条关键结论必须携带的状态：**有效** / **存疑** / **已否证** / **受限于环境**。

`存疑` 的含义不是"错的"，而是"不得被当作继续推导的前提"。

`受限于环境` 的含义不是"没验证"，而是"另一环境里已经验过、但**本会话复现不了**"（缺子进程/网络/图形界面/真机等）。
看到它就照 `INDEX` 的 §6 读环境限制，**不要当成 FAIL**。

## 冻结（frozen session）

交接完成后的旧会话所处状态：可查、可引用，不再推进。回退方式是再交接一次，而不是复活冻结会话。
